# 🎓 Telegram-бот для работы с расписанием ИРНИТУ

Этот проект — интеллектуальный **Telegram-бот для студентов Иркутского национального исследовательского технического университета (ИРНИТУ)**.

Бот позволяет получать актуальное расписание занятий с использованием естественного языка. Для обработки запросов используется **YandexGPT**, а данные о расписании хранятся в **PostgreSQL**.

Пользователь может узнать расписание на конкретную дату, найти ближайшую пару, выполнить поиск по предмету или преподавателю, а также изменить учебную группу.

---

## 📖 О проекте

Бот предназначен для упрощения доступа студентов к расписанию университета.

Вместо ручного поиска расписания на сайте студент может написать обычный вопрос:

> Какие пары у меня завтра?

или:

> Какая следующая пара?

или:

> Когда у меня будет матан?

Бот анализирует запрос с помощью YandexGPT, при необходимости использует специальные инструменты для получения данных из базы данных и возвращает пользователю готовый ответ.

### Основные возможности

* 📅 просмотр расписания на сегодня;
* 📆 просмотр расписания на завтра;
* 🗓 выбор произвольной даты;
* ⏭ поиск ближайшей пары;
* 🔎 поиск занятий по названию предмета;
* 👨‍🏫 поиск занятий по преподавателю;
* 👥 работа с расписанием конкретной учебной группы;
* 🔄 автоматическая загрузка отсутствующего расписания;
* 🤖 обработка вопросов на естественном языке с помощью YandexGPT;
* ⚙️ смена учебной группы;
* 💾 хранение пользователей и расписания в PostgreSQL.

---

## ⚙️ Как это работает

Основной сценарий работы выглядит следующим образом:

1. Пользователь отправляет сообщение в Telegram.
2. Telegram-бот получает сообщение через `aiogram`.
3. Сообщение передаётся в модуль обработки запросов.
4. YandexGPT анализирует запрос пользователя.
5. Если для ответа нужны данные расписания, модель вызывает соответствующий инструмент.
6. Инструмент обращается к PostgreSQL через SQLAlchemy.
7. Если необходимого расписания нет в базе, запускается загрузка расписания с сайта ИРНИТУ.
8. Полученные данные сохраняются в PostgreSQL.
9. YandexGPT получает результат выполнения инструмента.
10. Бот формирует понятный ответ и отправляет его пользователю.

## 🛠 Технологический стек

* **Python 3.12** — основной язык программирования;
* **aiogram** — взаимодействие с Telegram Bot API;
* **YandexGPT** — обработка запросов пользователей и генерация ответов;
* **Yandex Cloud API** — доступ к YandexGPT;
* **OpenAI Python SDK** — взаимодействие с совместимым API YandexGPT;
* **PostgreSQL** — хранение пользователей и расписания;
* **SQLAlchemy** — ORM для работы с PostgreSQL;
* **asyncio** — асинхронное выполнение операций;
* **python-dotenv** — загрузка переменных окружения;
* **BeautifulSoup / HTTP-клиенты** — получение данных с сайта расписания;
* **Tool Calling** — выполнение специализированных функций для получения данных расписания.

# 🚀 Установка и запуск

## 1. Клонировать репозиторий

```bash
git clone https://github.com/USERNAME/schedule-bot.git
cd schedule-bot
```

Замените `USERNAME` и название репозитория на свои данные после публикации проекта на GitHub.

---

## 2. Создать виртуальное окружение

### Linux / macOS

```bash
python3 -m venv .venv
source .venv/bin/activate
```

### Windows

```bash
python -m venv .venv
.venv\Scripts\activate
```

---

## 3. Установить зависимости

```bash
pip install -r requirements.txt
```

---

## 4. Настроить PostgreSQL

Создайте базу данных PostgreSQL и укажите параметры подключения в `.env`.

Пример:

```env
DB_HOST=localhost
DB_PORT=5432
DB_NAME=schedule_bot
DB_USER=postgres
DB_PASSWORD=your_password
```

---

## 5. Настроить Yandex Cloud

Создайте файл `.env` в корне проекта и добавьте ключи Yandex Cloud:

```env
YANDEX_API_KEY=your_yandex_api_key
YANDEX_FOLDER_ID=your_folder_id
```

---

## 6. Настроить Telegram

Добавьте токен Telegram-бота:

```env
TELEGRAM_TOKEN=your_telegram_bot_token
```

Токен можно получить через официального бота **BotFather**.

---

## 🔐 Переменные окружения

Полный пример `.env`:

```env
# PostgreSQL
DB_HOST=localhost
DB_PORT=5432
DB_NAME=schedule_bot
DB_USER=postgres
DB_PASSWORD=your_password

# Yandex Cloud
YANDEX_API_KEY=your_yandex_api_key
YANDEX_FOLDER_ID=your_folder_id

# Telegram
TELEGRAM_TOKEN=your_telegram_bot_token
```

⚠️ **Никогда не загружайте `.env` в GitHub.**

Для этого файл `.env` должен находиться в `.gitignore`:

```gitignore
.env
.venv/
__pycache__/
*.pyc
```

## 🧩 Основные модули

### `app/telegram/`

Модуль взаимодействия с Telegram.

Отвечает за:

* получение сообщений;
* обработку команд;
* отображение клавиатур;
* выбор даты;
* смену группы;
* отправку ответов пользователю.

Основной файл:

```text
handlers.py
```

---

### `app/assistant/`

Модуль работы с YandexGPT.

Содержит:

```text
client.py
```

Клиент YandexGPT и обработка запросов к модели.

```text
service.py
```

Формирование контекста пользователя и пользовательского запроса.

```text
tools_schema.py
```

Описание инструментов, которые доступны модели.

```text
tool_executor.py
```

Выполнение инструментов, вызванных YandexGPT.

---

### `app/database/`

Модуль работы с PostgreSQL.

Содержит модели SQLAlchemy и функции для выполнения запросов к базе данных.

В базе хранятся данные пользователей и расписание занятий.

---

### `app/parser/`

Модуль получения информации с сайта расписания ИРНИТУ.

Парсер определяет необходимые данные и получает расписание выбранной учебной группы.

---

### `app/services/`

Сервисный слой приложения.

`ScheduleLoaderService` отвечает за загрузку расписания и сохранение полученных данных в базу.

Если нужного расписания нет в PostgreSQL, сервис может инициировать его получение с сайта университета.

# 🤖 Возможности бота

## Просмотр расписания

Пользователь может использовать готовые команды и кнопки:

* расписание на сегодня;
* расписание на завтра;
* расписание на выбранную дату.

---

## 🔎 Поиск через YandexGPT

Бот понимает вопросы, сформулированные обычным языком.

Например:

```text
Какие пары у меня завтра?
```

```text
Какая у меня следующая пара?
```

```text
Когда у меня будет матан?
```

```text
Когда у меня пара у Иванова?
```

YandexGPT определяет намерение пользователя и при необходимости вызывает соответствующий инструмент.

---

## 👥 Работа с учебной группой

При регистрации пользователь указывает свою учебную группу.

Например:

```text
АСУб-24-1
```

После этого бот использует сохранённую группу при поиске расписания.

Пользователю не требуется каждый раз повторно указывать группу.

---

## 📥 Автоматическая загрузка расписания

Если необходимые данные отсутствуют в базе:

```text
Запрос пользователя
        ↓
Проверка PostgreSQL
        ↓
Расписание отсутствует
        ↓
Получение данных с сайта ИРНИТУ
        ↓
Сохранение в PostgreSQL
        ↓
Получение расписания
        ↓
Ответ пользователю
```

Это позволяет постепенно загружать актуальное расписание в базу данных по мере использования бота.

# 🗄 База данных

В проекте используется **PostgreSQL**.

Для взаимодействия с базой данных применяется **SQLAlchemy**.

Основные сущности:

### Пользователь

Хранит информацию о пользователе Telegram и его учебной группе.

```text
User
├── id
├── telegram_id
└── group_name
```

### Расписание

Хранит информацию о занятиях:

```text
Schedule
├── дата
├── время
├── предмет
├── преподаватель
├── аудитория
├── группа
└── подгруппа
```

---

# 🔧 Инструменты YandexGPT

YandexGPT может использовать специальные инструменты для получения информации из системы расписания.

Принцип работы:

```text
Пользователь
     ↓
"Какие пары завтра?"
     ↓
YandexGPT
     ↓
Определение необходимости инструмента
     ↓
Tool Calling
     ↓
Получение расписания из БД
     ↓
YandexGPT
     ↓
Формирование ответа
     ↓
Telegram
```

Благодаря этому модель **не придумывает расписание**, а получает фактические данные из базы.

---

# 🔄 Обновление расписания

Расписание получается с сайта университета и сохраняется в PostgreSQL.

Если данные за необходимую дату или неделю отсутствуют, приложение может автоматически загрузить соответствующую информацию.

Это позволяет поддерживать базу расписания актуальной без необходимости вручную добавлять каждое занятие.

# 📋 Команды бота

Основные команды и функции:

* `/start` — запуск бота и регистрация пользователя;
* **Сегодня** — расписание на текущий день;
* **Завтра** — расписание на следующий день;
* **Выбрать дату** — просмотр расписания на конкретную дату;

* **Поиск предмета** — поиск занятий по названию дисциплины;
* **Поиск преподавателя** — поиск занятий преподавателя;
* **Настройки** — изменение учебной группы.

Также пользователь может задавать вопросы непосредственно в свободной форме.
