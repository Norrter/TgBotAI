# 🎓 Telegram-бот расписания ИРНИТУ

Бот для студентов ИРНИТУ, который показывает расписание занятий и понимает вопросы на обычном языке — текстом или голосом. Запросы разбирает **YandexGPT**, расписание берётся с сайта университета и хранится в **PostgreSQL**.

Проект использует **Telegram вместо MAX по согласованию с проверяющим**.

Демонстрация работы — в папке [`examples/`](examples/).

## Возможности

* 📅 расписание на сегодня, завтра или любую дату;
* ⏭ текущая и ближайшая пара (в том числе завтра и в следующие дни);
* 🔎 поиск занятий по предмету и по преподавателю;
* 🤖 вопросы в свободной форме: «Какие пары у меня завтра?», «Когда будет матан?»;
* 🎤 голосовой ввод — вопрос можно отправить голосовым сообщением;
* 🔄 автоматическая загрузка расписания с сайта ИРНИТУ, если его ещё нет в базе;
* ⚙️ сохранение и смена учебной группы.

## Как это работает

```text
Telegram (aiogram)
      │
      ▼
Handlers ── кнопки и команды меню ──────────────┐
      │                                         │
      │ свободный текст / голос (SpeechKit)     │
      ▼                                         │
YandexGPT ── tool calling ──► инструменты       │
                                  │             │
                                  ▼             ▼
                         Schedule Loader ──► PostgreSQL
                                  │
                                  ▼
                           сайт ИРНИТУ (парсер)
```

1. Сообщение приходит в `app/telegram/handlers.py`. Кнопки и фразы вроде «меню» или «помощь» обрабатываются сразу, без нейросети.
2. Голосовое сообщение сначала распознаётся через Yandex SpeechKit и дальше обрабатывается как текст.
3. Свободный вопрос уходит в YandexGPT вместе со списком инструментов: расписание на день, текущая и следующая пара, поиск по предмету, поиск по преподавателю.
4. Модель выбирает инструмент, бот выполняет его и возвращает модели результат. Поэтому модель не придумывает расписание, а использует данные из базы.
5. Перед чтением из базы бот проверяет, загружена ли нужная неделя. Если нет — скачивает её с сайта ИРНИТУ и сохраняет.

## Стек

Python 3.10+, aiogram 3, YandexGPT (через OpenAI SDK), Yandex SpeechKit, PostgreSQL, SQLAlchemy + asyncpg, BeautifulSoup, Docker Compose.

## Установка и запуск

```bash
git clone https://github.com/Norrter/TgBotAI.git
cd TgBotAI

python3 -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

Создайте в корне проекта файл `.env`:

```env
# Telegram: токен от @BotFather
TELEGRAM_BOT_TOKEN=your_telegram_bot_token

# Yandex Cloud: YandexGPT и SpeechKit
YANDEX_API_KEY=your_yandex_api_key
YANDEX_FOLDER_ID=your_folder_id

# PostgreSQL (можно не указывать — это значение по умолчанию)
DATABASE_URL=postgresql+asyncpg://postgres:postgres@localhost:5433/schedule_bot

# Необязательно: прокси только для запросов к Telegram
TELEGRAM_PROXY=
```

API-ключ должен принадлежать сервисному аккаунту с ролями `ai.languageModels.user` (YandexGPT) и `ai.speechkit-stt.user` (распознавание голоса).

Запустите базу данных, создайте таблицы и стартуйте бота:

```bash
docker compose up -d
python -m app.database.init_db
python -m app.main
```

### Если Telegram доступен только через прокси

Укажите адрес в `TELEGRAM_PROXY`, например `socks5://127.0.0.1:1080`. Через прокси пойдут только запросы к Telegram — сайт ИРНИТУ и Yandex Cloud останутся напрямую.

Рабочий публичный SOCKS5-прокси можно подобрать скриптом, он сам запишет адрес в `.env`:

```bash
python -m app.find_proxy --save
```

Публичные прокси живут недолго: если бот перестал подключаться, запустите скрипт ещё раз.

## Использование

Команда `/start` открывает главное меню с кнопками: «Сегодня», «Завтра», «Выбрать дату», «Следующая пара», «Найти занятие», «Преподаватель», «Настройки», «Помощь».

При первом запуске укажите группу: «Настройки» → «Моя группа», например `АСУб-24-1`. Дальше бот использует её сам.

Вопрос можно написать или сказать голосом (до 30 секунд):

> Какие пары у меня завтра?
>
> Какая пара сейчас и какая следующая?
>
> Когда у меня будет матан?
>
> Открой меню

## Структура проекта

```text
app/
├── main.py                 # точка входа
├── config.py               # настройки из .env
├── find_proxy.py           # подбор прокси для Telegram
├── telegram/
│   ├── bot.py              # создание бота, прокси
│   ├── handlers.py         # кнопки, команды, текст и голос
│   └── keyboards.py        # клавиатуры
├── assistant/
│   ├── service.py          # формирование запроса к модели
│   ├── client.py           # клиент YandexGPT и tool calling
│   ├── tools_schema.py     # описание инструментов для модели
│   ├── tool_executor.py    # запуск выбранного инструмента
│   ├── tools.py            # сами инструменты
│   └── speech.py           # распознавание голоса (SpeechKit)
├── services/
│   └── schedule_loader_service.py   # загрузка недель, текущая и следующая пара
├── parser/
│   ├── group_parser.py     # поиск групп на сайте, кэш групп
│   └── schedule_parser.py  # разбор страницы расписания
└── database/
    ├── models.py           # таблицы users и schedule
    ├── repositories.py     # запросы к базе
    ├── database.py         # подключение
    └── init_db.py          # создание таблиц
data/groups_cache.json      # кэш «группа → ссылка на расписание»
docker-compose.yml          # PostgreSQL
```

Кэш групп пересобирается командой `python -m app.parser.group_parser`.

## База данных

* `users` — Telegram-пользователь и его учебная группа.
* `schedule` — занятия: дата, время, чётность недели, предмет, тип, преподаватель, группы, подгруппа, аудитория.

## Безопасность

Токены и ключи хранятся только в `.env`. Файл указан в `.gitignore` и не должен попадать в репозиторий.
